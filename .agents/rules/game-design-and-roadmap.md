# 硅谷人生重开模拟器 (Silicon Valley Life Reboot) - 核心设计规范与改进路线图

本文件为《硅谷人生重开模拟器》的核心设计规范、系统架构准则与长期迭代路线图，作为智能体（Agent）开发与维护本代码库时的常驻记忆与最高准则。

---

## 🎯 核心设计哲学 (Core Philosophy)

1. **真实的硅谷人生体验**：
   - 精准还原华人留学生/工程师在湾区的全生命周期体验（F1 ➔ OPT ➔ H1B ➔ 绿卡/排期 ➔ 买房 ➔ 职场内卷 ➔ 资产滚雪球 ➔ FIRE）。
   - 保持鲜明的黑色幽默、硅谷职场梗与时代共鸣（Blind、一亩三分地、237 公路、Model Y 撞车门、Nvidia 股票、沙丘路 VC 等）。
2. **长线人生积累而非短命暴死**：
   - 保证绝大多数局数的平均寿命在 **35 ~ 55 岁**，让玩家能充分体验 30 岁后的中年危机、L6 Staff 晋升、子女教育、长周期绿卡排期与高净值投资。

---

## ⚖️ 数值平衡与生命周期准则 (Balance & Longevity Rules)

1. **健康消耗与回血保护**：
   - **禁止极端单回合扣血**：除极少数明确的致命灾难外，常规选项单次扣血控制在 `5 ~ 15` 点之间，严禁单次扣除 20~30 点导致连续两回合猝死。
   - **充沛的回血机制**：提供多样化恢复手段（年假旅游、带薪休假、医美私教、宠物陪伴、大厂神仙食堂、冥想养生）。
   - **特质平衡**：【卷王之王】初始健康应保持在 90 以上，避免成为最易猝死的受苦角色。
2. **阶梯式 FIRE 通关体系**：
   - 避免初期几个暴富事件直接终局。
   - 建立分阶通关目标：
     - **基准 FIRE**：$500w（满足基本养老）
     - **舒适 FIRE**：$800w（中产独立屋 + 稳定被动收益）
     - **奢华 FIRE**：$1500w+（Atherton 豪宅 + 天使投资人）
   - 达成初始目标后，给予玩家“继续生活探索更高目标”或“立即退休结算”的选择权。

---

## 🛡️ 系统状态不变性与中间件守则 (State Invariants)

所有涉及状态变更的事件与组件均须严格遵守以下全局不变性法则：
1. **身份不可逆降级保护**：
   - 已获得【公民】或【绿卡】身份的玩家，终身豁免任何签证抽签、失业驱逐与 PERM 排期倒计时，严禁被任何后续事件覆盖降级。
2. **失业状态与 TC 约束**：
   - 当 `job_type === 'unemployed'` 或 `laid_off === true` 时，`tc` 必须归零，不得继续发放工资。
3. **资产与现金流联动**：
   - 商城及事件中若现金不足但持有股票，应支持主动/自动变现股票完成支付（如买房首付、购车、大额消费），避免“手握百万股票却因现金为 30w 而无法买房”的逻辑阻碍。
4. **时间单调递增**：
   - 年龄 `age` 与年份 `year` 必须单调递增，不可逆流。

## 🗺️ 功能演进路线图 (Improvement Roadmap)

### P0 (即刻修复与体验保障)
- [x] **修复商城买房判定**：将购买检查由纯现金改为 `(cash + stocks) >= 首付`，支持自动变现买房。
- [x] **优化【卷王之王】特质**：提升初始健康，给予做题晋升的正面反馈与高抗压加成。
- [ ] **重平衡健康扣除与回血**：下调常规内卷的扣血幅度，增强年假与日常养生回血。

### P1 (玩法深度与金融系统)
- [ ] **资产配置系统**：新增定投 S&P 500 / QQQ 指数基金功能，享受长期复利与分红。
- [x] **房产出租与被动现金流**：购买第二套房后可出租，每年产生稳定租金收益。
- [ ] **双职工家庭与子女教育**：伴侣收入合并、公立学区房 vs 顶尖私校教育分支。

### P2 (UI/UX 与数据可视化)
- [ ] **历年净资产走势曲线 (Net Worth Chart)**：记录玩家从 18 岁到退休的资产爬升曲线。
- [ ] **生涯大事记时间轴 (Career Timeline)**：实时记录升职、跳槽、买房、结婚、绿卡等里程碑。
- [ ] **扩充隐藏成就图鉴 (Codex)**：由 14 项扩充至 30+ 项，涵盖多种难度与特色流派。

### P3 (架构模块化重构)

  - `src/data/events/academic.ts`（学业院校）

  - `src/data/events/immigration.ts`（签证与绿卡长征）
  - `src/data/events/housing_finance.ts`（房产、商城与投资）
  - `src/data/events/relationship.ts`（相亲、婚恋与家庭）
