> **“刷题、抽签、裁员、升职、买房、收租、定投、FIRE...”**  
> 《硅谷人生重开模拟器》是一款基于 React 19 + TypeScript + Vite 构建的沉浸式硬核职场/生活模拟文字养成游戏。  
> 玩家将扮演一名在硅谷拼搏的华人工程师或留学生，在严苛的移民身份、大厂职级内卷、高房价房产投资、被动现金流构建与财富自由 (FIRE) 之间做出关键抉择，体验最真实而精彩的硅谷生存法则！

## ✨ 核心特色与玩法系统 (Core Features)

### 1. 🌟 隐藏款 SSR 天赋与防作弊持久化
- **【SSR·原生美籍】**：8% 概率开局刷出，专属金色霓虹卡牌特效。自带 $15w 留学专款与加州湾区老宅，终身豁免 H1B 抽签、PERM 排期与 60 天失业离境倒计时！
- **`localStorage` 种子防作弊机制**：开局结果由底层安全存储与随机种子绑定，刷新网页无法重置当前局天赋，唯有重启新人生方可重新判定。

### 2. 🎓 多元初始人设与学术/转码起点
- 自选核心特质：**小镇做题家**（刷题效率翻倍）、**家里有矿**（自带百万启动资金）、**卷王之王**（抗压极强且绩效提升）、**湾区海王**（约会恋爱加成）、**AI 天才**（大模型领域神级增益）等。
- 自由选择毕业院校（Stanford、CMU、MIT、UCB、理工强校、国内公立等）与攻读学位（本科 / 硕士 / 直博 PhD），亦可选择**非科班转码 (Bio/Chem/文商科 自学/Bootcamp)** 逆袭上岸路线。

### 3. 💼 深度职场演进与大厂职级攀登
- **真实职级跃迁**：从 L3 萌新程序员一路晋升至 L4/L5 中坚骨干，跨越天堑至 **L7 Senior Staff 资深架构师** 与顶峰 **L8 Principal 首席架构师**。
- **多元职业赛道**：涵盖 FAANG 巨头、NVIDIA 芯片新贵、OpenAI MTS / Anthropic AI 研究员、Quant 顶级对冲基金操盘手，亦可组建团队开启 AI Agent 创业并冲刺纳斯达克 IPO 敲钟！

### 4. 🛂 硬核严谨的美国签证与身份链条
- **全真实模拟**：`F1 (学生) ➔ OPT (实习) ➔ H1B 抽签 (3次机会) ➔ Day 1 CPT 紧急挂靠 ➔ L1 温哥华外派避难 ➔ EB-1A / PERM 绿卡排期 ➔ 美国公民`。
- **全局身份不变性**：底层中间件保障绿卡与公民身份不可逆降级，真实呈现 60 天 Grace Period 紧急找工、ICC 挂靠与排期锁定机制。

### 5. 🏡 房产帝国与被动现金流系统 (Passive Income)
- **多阶层房产置业**：Sunnyvale 老破小、North San Jose 联排、Fremont 10分学区房、Atherton 顶级豪宅。
- **被动现金流矩阵**：支持后院加盖 ADU 出租、购置外州远程投资房、盘下 Sunnyvale 4-Plex 四户公寓楼收租，达成年租金 $10w+ 被动收入，解锁【现金流之王】！

### 6. 📈 智能资产流动性兜底与多元金融
- **自动卖股平仓救急 (Auto Stock Liquidation)**：现金流告急时系统自动平仓持仓股票抵扣房贷与大额消费，拒绝无逻辑暴毙。
- **美股指数定投**：支持开启 VOO 指数基金年终自动定投，享受复合收益与分红再投资。
- **全职 Day Trader 操盘与宏观博弈**：支持持绿卡全资操盘，包含重仓科技龙头、0DTE 期权、SQQQ 熊市反向做空对冲与量化自动套利算法。

### 7. 🎯 阶梯式 FIRE 目标与自由探索模式
- 支持设定多档退休追求：**基础温饱 ($500w)** / **舒适中产 ($800w)** / **奢华自由 ($1500w)** / **硅谷百亿传奇 ($3000w+)**。
- 达成初始目标后，玩家可自主选择**“功成身退，立即结算”**或**“继续探索，冲刺更高巅峰”**！

### 8. 📊 历年资产走势图 & 生涯大事记 Timeline
- **交互式财富折线图**：动态回放从 22 岁初入硅谷到财务自由的资产净值演进曲线与流动性构成。
- **编年大事记**：详细复盘每一年发生的技术浪潮、裁员风波、恋爱买房、职级晋升与跳槽历史。

### 9. 🏆 27+ 隐藏成就图鉴 (Achievement Codex)
- 内置数十项具有暗号线索的成就图鉴：【AI 独角兽创始人】、【黑色皮衣挂机战神】、【逆风翻盘·转码神话】、【温哥华 L1 养老仙人】、【湾区神仙眷侣】、【ICU 战神重生】、【华尔街之狼】、【硅谷百亿传奇】等。

### 10. 📱 现代化 Bento Grid 响应式仪表盘 & 原生动态音效
- 采用 Bento Grid 风格仪表盘，全端响应式适配手机、平板与桌面。
- 纯程序化 Web Audio API 动态合成音效，支持全局一键静音与键盘无障碍焦点管理。

## 🛠️ 技术栈与架构亮点 (Tech Stack & Architecture)

- **前端核心**：React 19 + TypeScript 6.0 + Vite 8
- **样式与布局**：Tailwind CSS 3.4 + Bento Grid Responsive Design
- **架构设计**：
  - **事件解耦**：231+ 剧情事件按领域拆分至 `src/data/events/` 独立子模块，统一集中导出。
  - **全局中间件**：`applyStateTransitions` 统一拦截状态变更，严格维护身份防降级、失业 TC 归零、历史最高职级保存 (`max_level`)、流动性平仓等全局不变性（Invariants）。
  - **持久化防作弊**：`safeStorage` + 确定性 PRNG 随机数生成器。

| **3. `test_routing_guards.ts`** | 路由防劣化棘轮机制 (Ratchet)，严禁新增基于文案子串的分支路由，强制驱动状态化控制流。 |
| **4. `test_all_cujs.ts`** | **55 大核心用户旅程 (CUJs)** 场景级端到端测试，1,600+ 项断言 100% 通过。 |
| **5. `fuzz_test.ts`** | **10,000 局**全自动随机决策 Fuzzing，验证 500,000+ 次状态流转的状态不变性。 |
| **6. `test_monte_carlo_balance.ts`** | **3,000 局**蒙特卡洛数值平衡模拟，确保平均寿命 35~55 岁、FIRE 胜率 20%~40%。 |
| **7. `test_runtime_coverage.ts`** | **8,000 局**真实统一路由运行时覆盖审计，确保无新增死事件与板块孤岛（覆盖率 >= 97%）。 |
| **8. `test_story_flags_hygiene.ts`** | Story Flag 卫生审计，比对全量 Flag 写入 vs 读取，杜绝死 Flag。 |
| **9. `test_harness_matchers.ts`** | 测试机器人导航选择器防漂移门禁，验证所有文本 Matcher 指向真实有效选项。 |

## 📦 快速开始 (Quick Start)

### 环境要求
- [Node.js](https://nodejs.org/) (`>= 18.0`)
- `npm` / `pnpm` / `yarn`

### 本地开发与运行

1. **克隆代码仓库**
   ```bash
   git clone https://github.com/DeanChensj/sv-life-reboot.git
   cd sv-life-reboot
   ```

2. **安装依赖**
   ```bash
   npm install
   ```

3. **启动本地开发服务器**
   ```bash
   npm run dev
   ```
   启动后在浏览器中访问 `http://localhost:5173` 即可畅玩！

4. **运行全量自动化测试**
   ```bash
   npm test
   ```

5. **代码静态检查**
   ```bash
   npm run lint
   ```

6. **打包与部署**
   ```bash
   # 打包生产版本
   npm run build

   # 一键部署至 GitHub Pages
   npm run deploy
   ```
